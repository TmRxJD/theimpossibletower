# The Impossible Tower

A full-screen rhythm platformer: jump and dash across a rising tower while a fast enemy climbs toward you. Play on desktop with keyboard controls or on touch screens with on-screen controls. The game scales to phone, tablet, and desktop viewports and uses procedural Web Audio in the public build.
